# Инструкция: запуск Telegram Mini App для стоматологии

Ничего писать не нужно — только регистрироваться, копировать ключи и нажимать кнопки.
Весь код уже готов. Идём по порядку.

---

## Шаг 0. Впишите реальные данные клиники

Название клиники (Dr. Radjabov) и цены на услуги уже вписаны в файл
`lib/clinic-config.js` по данным, которые вы прислали. Но три вещи заказчик
пока не давал — без них ассистент не сможет ответить правильно, найдите в
файле пометки `// TODO:` и впишите:
- `address` — реальный адрес клиники (сейчас "уточняется у администратора")
- `phone` — реальный номер телефона
- `workingHours` — часы работы

Как только появятся реальные имена врачей — замените `doctorGenderOptions`
на список докторов с именами и специализациями (в коде есть пример в
комментарии рядом), тогда в форме записи пациент увидит конкретного врача,
а не только пол.

Это единственный файл в проекте, куда нужно вписывать текст руками.

## Шаг 1. Создать бота в Telegram

1. Откройте Telegram, найдите **@BotFather**, нажмите Start.
2. Отправьте `/newbot`, придумайте имя и username (должен заканчиваться на `bot`,
   например `dental_smile_bot`).
3. BotFather пришлёт **токен** вида `123456789:AAExampleToken...` — скопируйте
   его в заметки, он понадобится в Шаге 4.

Кнопку меню (чтобы приложение открывалось прямо из чата с ботом) настроим в
конце, в Шаге 6 — сначала нужен адрес самого приложения.

---

## Шаг 2. Завести Supabase (база данных для записей)

1. Зайдите на **supabase.com** → Sign Up (можно через GitHub) → New Project.
2. Придумайте пароль для базы (просто сохраните его куда-нибудь), выберите
   ближайший регион, дождитесь создания проекта (1-2 минуты).
3. Слева в меню откройте **SQL Editor** → New query.
4. Откройте файл `supabase-setup.sql` из проекта, скопируйте всё содержимое,
   вставьте в редактор и нажмите **Run**. Появится таблица `bookings`.
5. Слева откройте **Project Settings → API**. Скопируйте и сохраните:
   - **Project URL** (это будет `SUPABASE_URL`)
   - **service_role key** (это будет `SUPABASE_SERVICE_KEY`) — он скрыт под
     кнопкой "Reveal", не путайте с anon key.

---

## Шаг 3. Получить ключ нейросети (бесплатно, без карты)

1. Зайдите на **aistudio.google.com** → войдите через обычный Google-аккаунт
   (Gmail).
2. Слева или сверху найдите **Get API key → Create API key**.
3. Скопируйте ключ (начинается на `AIza...`) — это будет `GEMINI_API_KEY`.
   Карту привязывать не нужно — бесплатный тариф даёт около 1500 запросов в
   день, для одной клиники этого более чем достаточно.

Если позже захотите перейти на Claude (обычно чуть качественнее отвечает,
но платно) — просто напишите, помогу переключить одним файлом.

---

## Шаг 4. Загрузить проект на GitHub

1. Зайдите на **github.com** → зарегистрируйтесь, если ещё нет аккаунта.
2. Нажмите **+ → New repository**, назовите его, например, `dental-mini-app`,
   оставьте Public или Private — не важно. Create repository.
3. На странице пустого репозитория нажмите **uploading an existing file** и
   перетащите туда всю папку проекта (все файлы и папки `api`, `lib`,
   `public`, `package.json` и т.д.) → Commit changes.

Если вы уже правили `lib/clinic-config.js` из Шага 0 — редактировать текст
можно прямо на GitHub: открыть файл → карандаш "Edit" → изменить → Commit.

---

## Шаг 5. Задеплоить на Vercel

1. Зайдите на **vercel.com** → Sign Up **через GitHub** (это свяжет аккаунты
   автоматически).
2. **Add New → Project** → найдите репозиторий `dental-mini-app` → Import.
3. Ничего не меняя в настройках сборки, откройте **Environment Variables** и
   добавьте по одной все переменные из файла `.env.example` этого проекта, но
   уже с вашими реальными значениями:
   - `TELEGRAM_BOT_TOKEN` — из Шага 1
   - `SUPABASE_URL` и `SUPABASE_SERVICE_KEY` — из Шага 2
   - `GEMINI_API_KEY` — из Шага 3 (бесплатный ключ Google AI Studio)
   - `REMINDER_SECRET` — придумайте любую длинную случайную строку сами
     (например, надёжный пароль)
4. Нажмите **Deploy**. Через минуту Vercel даст вам ссылку вида
   `https://dental-mini-app-xxxx.vercel.app` — это и есть готовое приложение.
   Откройте её в браузере и убедитесь, что страница загружается (чат может не
   отвечать вне Telegram — это нормально, дальше подключим бота).

---

## Шаг 6. Подключить приложение к боту

1. Вернитесь в Telegram к **@BotFather** → `/mybots` → выберите вашего бота.
2. **Bot Settings → Menu Button → Configure Menu Button**.
3. Пришлите ссылку на приложение из Шага 5 (`https://....vercel.app`),
   затем — текст кнопки, например `Открыть клинику`.
4. Откройте чат с вашим ботом в Telegram — внизу рядом с полем ввода появится
   кнопка, открывающая мини-приложение. Проверьте чат и запись на приём.

---

## Шаг 7. Подключить напоминания (внешний планировщик)

Бесплатный тариф Vercel не умеет запускать проверки чаще раза в сутки, а
напоминания нужно проверять каждые 15-30 минут — поэтому используем бесплатный
внешний сервис.

1. Зайдите на **cron-job.org** → зарегистрируйтесь бесплатно.
2. **Create cronjob**:
   - URL: `https://ваш-адрес.vercel.app/api/remind?secret=ВАШ_REMINDER_SECRET`
     (тот самый секрет, что вы вписали в Vercel на Шаге 5)
   - Execution schedule: **Every 15 minutes**
3. Save. Готово — теперь пациенты будут получать напоминание за 24 часа до
   приёма (это число можно изменить в `lib/clinic-config.js`, поле
   `reminderHoursBefore`).

## Проверка перед сдачей заказчику

- [ ] В шапке приложения отображается настоящее название клиники
- [ ] Ассистент в чате правильно называет услуги, цены и врачей
- [ ] Форма записи сохраняет данные (проверьте в Supabase → Table Editor → bookings)
- [ ] После записи в Telegram приходит подтверждение
- [ ] Тестовая запись на ближайшее время получает напоминание (можно
      временно поставить `reminderHoursBefore: 0.05` — сработает почти сразу —
      и вернуть обратно после проверки)
- [ ] Кнопка в меню бота открывает приложение

## Если что-то не работает

- Ошибка в чате → в Vercel откройте **Project → Deployments → (последний) →
  Functions → api/chat.js → Logs**, там будет причина.
- Форма записи не сохраняется → проверьте, что `SUPABASE_SERVICE_KEY` —
  именно service_role, а не anon key.
- Напоминания не приходят → проверьте в cron-job.org вкладку **History**,
  видит ли он ошибку при обращении к `/api/remind`.
